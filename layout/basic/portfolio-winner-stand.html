위너 독서대

학습과 문구 카테고리는 기능 설명이 중요하지만, 너무 판매형으로 보이면 금방 피로해집니다. 위너 독서대는 사용 장면과 제품의 안정감을 먼저 보이도록 구성해 신뢰를 만드는 방향에 집중했습니다.

Study

Winner

공부 환경과 잘 맞는 정리된 화면, 또렷한 사용 맥락, 과하지 않은 정보 배치가 핵심인 프로젝트입니다.

Project Overview

학습 환경의 안정감을 강조하고
제품 쓰임새를 차분하게 보여주는 구조

위너 독서대는 사용 상황이 명확한 제품이라 화면도 목적이 분명해야 했습니다. 그래서 학생과 책상, 공부 공간이 연상되는 흐름을 우선 설계하고, 기능은 그 다음에 읽히도록 순서를 조정했습니다.
