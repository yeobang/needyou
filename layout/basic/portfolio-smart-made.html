Project Overview

오브제처럼 보이지만
실사용 정보는 또렷하게 남는 구성

스마트메이드 스탠드는 책상 위 환경과 바로 연결되는 제품이기 때문에, 화면도 잡다해 보이면 안 됐습니다. 배경 요소를 줄이고 제품 위치를 정갈하게 배치한 뒤, 필요한 정보만 빠르게 읽히도록 구조를 단순화했습니다.

Design Point

제품이 작을수록
화면은 더 정교해야 합니다

시각적인 볼륨이 크지 않은 제품은 레이아웃이 더 중요합니다. 그래서 여백의 밀도를 조정하고, 이미지 한 장 한 장이 기능보다 분위기를 먼저 만들도록 설계했습니다. 과하지 않은 호버와 리빌만 남겨 심플하지만 디자인틱한 인상을 유지했습니다.
